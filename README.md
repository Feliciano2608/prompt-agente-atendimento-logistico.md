# prompt-agente-atendimento-logistico.md
Projeto desenvolvido no bootcamp Bradesco – Agentes de IA do Zero à Prática, da DIO. Criação de um prompt para agente de atendimento logístico via WhatsApp, aplicando engenharia de prompt, IA generativa, proteção de dados, empatia e confiabilidade nas informações sobre pedidos, entregas e ocorrências.
